## 📌 О проекте

Проект посвящён прогнозированию продаж продуктов одной известной крупной компании, название которой созвучно с планетой.

В работе будет использоваться датасет с историческими продажами за несколько лет, включающий показатели по различным категориям продуктов.

Основная задача — разработать модель прогнозирования, которая учитывает сезонность, циклические изменения и долгосрочные тренды. В рамках проекта планируется сравнить статистические подходы и модели машинного и глубокого обучения.

Итоговое решение будет включать модель прогнозирования и аналитический интерфейс для визуализации прогнозов и отслеживания динамики продаж.

> Статус проекта: планирование. Описанные ниже модели, инструменты и результаты являются планируемыми.

## 🎯 Итоговая тема проекта

Разработка и сравнение статистических и ML/DL-моделей прогнозирования продаж продуктов крупной компании с учётом сезонности, цикличности и долгосрочных трендов.

## 🎯 Цель проекта

Разработать модель прогнозирования продаж на основе исторических данных, оценить её качество и представить результаты в удобном аналитическом интерфейсе.

Решение должно учитывать особенности временных рядов и позволять анализировать прогнозируемую динамику продаж по выбранным продуктам или категориям.

## 📋 Основные задачи

1. Изучить структуру датасета и согласовать постановку задачи.
2. Подготовить данные для анализа и моделирования.
3. Провести разведочный анализ данных — EDA.
4. Визуализировать временные ряды продаж.
5. Выявить сезонные, циклические и трендовые компоненты.
6. Построить простые базовые прогнозы для сравнения.
7. Обучить статистические модели ARIMA, SARIMA и ETS.
8. Реализовать ML-модели, например Random Forest и XGBoost.
9. Проверить применимость DL-моделей LSTM / GRU.
10. Сравнить качество прогнозов по метрикам RMSE, MAE и MAPE.
11. Проанализировать ошибки моделей и факторы, связанные с изменением спроса.
12. Разработать сервис или дашборд для визуализации прогнозов.
13. Подготовить документацию, итоговый отчёт и демонстрацию решения.

## 🧠 План моделирования

Модели будут разрабатываться последовательно: от простых базовых решений к более сложным подходам.

| Группа | Планируемые модели | Задача этапа |
|---|---|---|
| Базовые прогнозы | Наивный и сезонный наивный прогноз | Получить отправную точку для сравнения |
| Статистические модели | ARIMA, SARIMA, ETS | Оценить качество классических подходов |
| Машинное обучение | Random Forest, XGBoost | Проверить подход на основе сформированных признаков |
| Глубокое обучение | LSTM / GRU | Оценить применимость нейросетевых моделей |
| Итоговое решение | Выбранная модель или набор моделей | Подготовить прогнозы для аналитического интерфейса |

Для ML-подходов планируется рассмотреть лаговые значения продаж, скользящие статистики, календарные и дополнительные доступные признаки.

Необходимость обучения каждой модели будет оцениваться с учётом объёма данных, сроков проекта и доступных вычислительных ресурсов.

2. Зафиксировать общий горизонт прогнозирования.
3. Использовать одинаковые условия оценки для сравниваемых моделей.
4. Проверить отсутствие использования будущих данных при подготовке признаков.
5. Сравнить модели с простыми базовыми прогнозами.
6. Рассчитать метрики на отложенном периоде.
7. Проанализировать ошибки по продуктам, категориям и временным интервалам.
